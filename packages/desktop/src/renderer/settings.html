MultiDSH · 连接、设备与 DSH 主机实例

连接与外观

Directory 地址只影响当前客户端的连接；每个 DSH 实例会保存自己的池身份。

切换 Directory 会断开当前池，需要重新创建或加入。

外观
主机页签缓存

关闭主机时页面只隐藏、不销毁，再次打开可以直接显示（实测可省 1.7–4.6 秒）。 这里设置最多保留几个最近打开过的页面，每个页面约占 100–200 MB 内存；设为 1 表示只保留当前页。

演示模式

只显示示例设备，不连接 Directory，也不会修改池或主机。你可以随时进入或退出。

DSH 主机实例

每台机器可以同时拥有多个实例，每个实例有自己的 host.json、DSH_HOME、端口和 DSH 登录/API key； 启动已有实例不会重新初始化，设备身份和登录状态会保留。

新建实例

创建后会以 host 身份加入当前池，需要在主界面的「待审批」里由池主批准。DSH_HOME 里保存该实例的登录和 API key；填一个已有目录可以复用原来的登录状态。
